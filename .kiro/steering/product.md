# Portal Pet Care

Aplicação web para gerenciamento de planos de saúde animal.

## Funcionalidades

- Home: landing page com planos e CTAs
- Login: autenticação via AWS Cognito
- Venda de Plano: fluxo multi-step para contratação (Básico R$49,90 / Plus R$89,90 / Premium R$149,90)
- Cadastro do Animal: formulário dinâmico com upload de foto (máx 3 pets por usuário)
- Agenda: calendário com slots para consultas e exames (09-11h, 14-16h)
- Área Financeira: faturas com status pago/pendente/vencido
- Carteirinha: visualização estilo cartão do plano e animal

## Contexto

Este repositório contém o material de treinamento (guias, prompts, checklists) para um treinamento prático de 3 semanas usando Kiro IDE & CLI. O código é desenvolvido ao vivo durante as sessões.

## Idioma

O projeto é em português brasileiro. Documentação, comentários e mensagens ao usuário devem ser em pt-BR.
